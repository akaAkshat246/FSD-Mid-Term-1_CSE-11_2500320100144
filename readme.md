## Getting Started

### 1. Prerequisites
- Node.js (v18+)
- npm

### 2. Installation
Install the dependencies:
```bash
npm install
```

### 3. Run the Server
To start the server:
```bash
npm start
```

For development mode (with watch mode):
```bash
npm run dev
```

The server will be available at: `http://localhost:3000`
